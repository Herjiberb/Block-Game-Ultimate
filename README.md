# Block-Game-Ultimate

Block Game Ultimate is a 2d sandbox adventure and exploration game. It is focused on creating tools, designing structures, terraforming the world, and making it yours. It has texture and skin support and a full achievement and seasonal system.

---

## Features
- Play in vast world of blocks and cool art
- Upload your own skins and textures to create your own experience
- Runs in any up-to-date browser like Chrome or Edge
